# LSCC Finance Manager V6.1.5

## UI and workflow adjustments
- Added inline edit workflow for project partners: Edit pre-fills the partner form and changes the action to Save Changes.
- Added inline edit workflow for Home Cells.
- Added inline edit workflow for Church Calendar events.
- Added inline edit workflow for Special Departments.
- Added Edit action and inline edit workflow for Special Department members.
- Added inline edit workflow for Administrator user details in Settings.
- Removed the global Print button from the top application header; printing remains available only in designated report, planning, and receipt areas.

## Branding
- Added the supplied Liberty Synagogue Christian Church logo to the login box.
- Added the logo above LSCC Finance Manager in the dashboard/sidebar branding.
- Added the logo to the top-left of printed contribution and Mercy receipts.
- Added a static logo route for cloud deployment.

## Data and security
- No Supabase schema changes are required.
- Existing cloud persistence, password reset, and Resend configuration are retained.
