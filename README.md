# LSCC Finance Manager V6 — Cloud Edition

Cloud-ready multi-device edition of LSCC Finance Manager.

## Includes
- Existing V5 finance, membership, projects, Mercy Ministry, Special Departments, planning, calendar, Apostle's Office, reports and transaction management.
- Central PostgreSQL/Supabase-backed database.
- Authenticated cloud synchronization.
- Revision conflict protection.
- HTTPS-ready deployment.
- Dockerfile and Render deployment configuration.
- JSON backup migration script.

See `DEPLOY-CLOUD.md` for deployment and migration steps.
