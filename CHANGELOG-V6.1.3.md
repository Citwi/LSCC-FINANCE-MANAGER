# LSCC Finance Manager V6.1.3

- Added online email password reset links using Resend.
- Added login headline: “Lighting up the world”.
- Project contributions now search the partner database by name, partner ID, or linked church membership number and autofill partner name, ID, and contact.
- Partner inquiry now searches partners by name or ID with a matching dropdown.
- Mercy Support contributor search provides matching dropdowns and autofills membership details.
- Special Department member search provides matching dropdowns and autofills main membership details. Parent/guardian fields appear only when the selected member is Sunday School type.
- Administrators can add/remove member types and membership departments from Settings.
- Added overall Project Progress pie chart to the dashboard.
- Existing Supabase schema is unchanged.
